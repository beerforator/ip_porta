# Установка темы ИБ Портал на WordPress (локальный сервер)

## Шаг 1. Скопировать тему на сервер

Скопируй папку `wp-ib-portal` целиком в директорию тем WordPress:

```
/путь/к/wordpress/wp-content/themes/wp-ib-portal/
```

Если WordPress развернут через XAMPP/MAMP/OpenServer, путь будет примерно:

- **XAMPP (macOS)**: `/Applications/XAMPP/htdocs/wordpress/wp-content/themes/`
- **MAMP (macOS)**: `/Applications/MAMP/htdocs/wordpress/wp-content/themes/`
- **OpenServer (Windows)**: `C:\OpenServer\domains\wordpress\wp-content\themes\`

## Шаг 2. Активировать тему

1. Зайди в админ-панель WordPress: `http://localhost/wordpress/wp-admin/`
2. **Внешний вид → Темы**
3. Найди тему **«ИБ Портал»** и нажми «Активировать»

## Шаг 3. Настроить постоянные ссылки

1. **Настройки → Постоянные ссылки**
2. Выбери **«Название записи»** (Post name)
3. Нажми «Сохранить изменения»

Это нужно чтобы страницы открывались по красивым URL (`/news/`, `/documents/` и т.д.).

## Шаг 4. Создать страницы

Создай 5 страниц с указанными ярлыками (slug), выбрав соответствующий шаблон:

| Заголовок страницы | Ярлык (slug) | Шаблон |
|---|---|---|
| Отдел Информационной Безопасности | `home` | Главная страница |
| Новости по информационной безопасности | `news` | Новости |
| Документы и политики ИБ | `documents` | Документы |
| Генератор паролей | `password` | Генератор паролей |
| Тестирование и опросы | `polls` | Тестирование |

Как создать:
1. **Страницы → Добавить новую**
2. Введи заголовок (например, «Новости по информационной безопасности»)
3. Справа в блоке «Ярлык» (slug) напиши, например, `news`
4. Справа в блоке «Атрибуты страницы» → «Шаблон» выбери нужный
5. **Контент страницы оставь пустым** (всё вшито в шаблон)
6. Нажми «Опубликовать»

## Шаг 5. Сделать главную страницей

1. **Настройки → Чтение**
2. «На главной странице отображать» → выбери **«Статическую страницу»**
3. «Главная страница» → выбери **«Отдел Информационной Безопасности»**
4. Нажми «Сохранить изменения»

## Шаг 6. Добавить контент (наполнение)

### Новости
1. **Новости ИБ → Добавить новость**
2. Заголовок, текст, установи картинку записи
3. Опубликовать

### Документы
1. Сначала создай разделы: **Документы ИБ → Разделы** (например, «Политики», «Регламенты», «Инструкции»)
2. **Документы ИБ → Добавить документ**
3. Заголовок (название файла), выбери раздел
4. Внизу в блоке «Произвольные поля» добавь одно из двух:
   - `ib_file_url` — прямая ссылка на файл (проще всего)
   - `ib_file_id` — ID вложения из Медиафайлов (правильнее)
5. Если не видно блока «Произвольные поля» — нажми «Настройки экрана» вверху и включи галочку

### Тесты
1. **Тесты ИБ → Добавить тест**
2. Заголовок, описание — как обычно
3. В произвольных полях добавь поле `ib_questions` со значением в JSON-формате:

```json
[
  {
    "question": "Сколько символов минимум должно быть в пароле?",
    "answers": ["6", "8", "12", "16"],
    "correct": 2
  },
  {
    "question": "Можно ли открывать вложения от неизвестных отправителей?",
    "answers": ["Да", "Нет", "Только если файл .pdf", "Только на Mac"],
    "correct": 1
  },
  {
    "question": "Что делать с найденной в офисе флешкой?",
    "answers": ["Вставить в ПК", "Выкинуть", "Отнести в отдел ИБ", "Взять домой"],
    "correct": 2
  }
]
```

Где:
- `question` — текст вопроса
- `answers` — массив вариантов ответа
- `correct` — индекс правильного ответа (начиная с 0)

**Важно**: Если блок «Произвольные поля» не виден — нажми «Настройки экрана» (три точки вверху справа) и включи «Произвольные поля».

### Результаты тестов
Сохраняются автоматически при прохождении тестов. Смотреть: **Тесты ИБ → Результаты**.

## Готово!

После выполнения всех шагов сайт будет доступен по адресу `http://localhost/wordpress/` с полным функционалом:

- `/` — главная с hero-блоком и карточками последних новостей
- `/news/` — сетка новостей
- `/documents/` — аккордеон с документами по разделам
- `/password/` — генератор паролей (работает сразу, без контента)
- `/polls/` — тестирование (нужно добавить тесты)

## Совет

Установи бесплатный плагин **Advanced Custom Fields (ACF)** — он сильно упрощает добавление произвольных полей (`ib_file_url`, `ib_questions`) через удобный интерфейс вместо JSON-редактора.

## Возможности локальной версии

- В документах есть поиск и переключатель «Плитка / Список». Выбор сохраняется в браузере. Ссылка вида `/documents/?doc=123` раскрывает нужный раздел и показывает выбранный PDF прямо на странице; для других форматов даёт кнопку открытия файла.
- В редакторе новости есть блок «Ссылки на документы» с готовыми адресами. Скопируй адрес нужного документа и добавь его как обычную ссылку в текст. Альтернатива — шорткод `[ib_document id="123" title="Открыть документ"]`.
- В блоке «Метка новости» можно включить «Новое». Метка показывается только у отмеченных новостей.
- Карточка новости ведёт на отдельную страницу с заголовком, основным изображением, текстом и счётчиком открытий. Чтобы фото появилось, назначь записи «Изображение записи».
- Поиск на страницах новостей, документов и тестов фильтрует видимые элементы без перезагрузки.
- Новый результат теста показывает в админке итог, каждый выбранный ответ, ошибки, IP, учётную запись WordPress и сетевую учётную запись, если сервер передаёт `REMOTE_USER`. Старые результаты содержат только итог: ответы для них ранее не сохранялись.

Браузер не сообщает сайту достоверное имя пользователя компьютера. Для надёжной идентификации сотрудников потребуется корпоративная авторизация (например, AD/SSO) с передачей `REMOTE_USER`; введённое вручную имя можно подделать. Локальный Docker может показывать IP своего шлюза вместо адреса рабочего ПК.
